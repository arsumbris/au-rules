# don't restate what the engine serves

The engine already serves the structure of the vault.
Do not copy that structure into prose.

It serves the structure live and checks it:
- the type a note claims and the fields it fills
- what links to a note and what it links to
- what is mounted and what is broken
- and anything else a read returns

Prose that repeats this is a second copy that no one checks.
The graph moves and the copy goes stale.
So a reader who trusts it is now wrong.

Write the judgment instead.
A read returns the structure, never the judgment behind it.

To check, ask if a typed read would return what you just wrote.
If it would, cut the prose and let the read serve it.
